# vhdl-a1

In this VHDL assignment, we were introduced to the Quartus Prime Lite design software for writing VHDL code and then verifying it using ModelSim. This was applied to two separate tasks.

The first task involved implementing an OR gate in VHDL, along with a corresponding testbench to verify whether the test code was correct. Furthermore, we then generated the associated circuit and simulation 
on ModelSim, where the waveforms represented the OR gate as expected.

Next, we applied the skills learned from the first task and implemented them for the XNOR gate, again verifying the correctness of the code through the same process and producing the corresponding circuit and
simulation as seen below in the screenshots.
